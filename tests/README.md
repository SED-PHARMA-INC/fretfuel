## 验证限制

- 当前店铺两件真实商品均未填写商品类型。九个线上分类查询能验证正常打开且不混入未归类商品，但无法验证真实已归类商品的正例。合并并完成商品归类后，应补做这项验证。
- 本地工具渲染真实 Liquid 区块、商品卡片、分类图片和分页片段，但由适配器替代 Shopify 的 schema、搜索过滤和 paginate 执行。浏览器中的测试商品和商品详情终点为合成数据，不能替代 Shopify 原生集成验证。
- 基线比较使用基线的首页、搜索、集合区块，以及当前的片段、首页配置和 schema；这些片段在本次 PR 中未修改。它验证本次区块改动的回归情况，未重建整个历史店铺。
- 没有部署未合并主题、修改店铺商品/集合，也没有对线上店铺做压力测试或下单。

## 本地复跑

在此仓库根目录运行以下 PowerShell 命令；基线提交必须在本地 Git 历史中：

```powershell
python -m venv "$env:TEMP\fretfuel-category-venv"
& "$env:TEMP\fretfuel-category-venv\Scripts\python.exe" -m pip install -r tests/requirements.txt
& "$env:TEMP\fretfuel-category-venv\Scripts\python.exe" -m unittest discover -s tests -v
& "$env:TEMP\fretfuel-category-venv\Scripts\python.exe" tests/category_harness.py --benchmark c0f70e59f2275968afaa05fe44be6575db19c6bf
shopify theme check
git diff --check
```

需要浏览器检查时运行：

```powershell
& "$env:TEMP\fretfuel-category-venv\Scripts\python.exe" tests/category_harness.py --serve 8766
```

打开 `http://127.0.0.1:8766/`。这是只含合成商品的本地测试页面；结束后使用 Ctrl+C 停止服务器。线上冒烟、安全公告查询和浏览器操作未纳入默认离线单元测试，需分别执行。
